# 📊 Warehouse Data Analysis with Python & Jupyter Notebook

## 📌 Project Overview

This project focused on using simple data analysis to support a warehouse management improvement initiative at an automotive OEM.

I worked as Solution Consultant and used Python in Jupyter Notebook to analyze inventory and material data from a prototype warehouse.

My role was not that of a data analyst or data scientist. I used basic analytical methods and libraries such as pandas, NumPy, Matplotlib and Seaborn to structure raw data, answer specific business questions and provide input for the wider SAP EWM process design.

---

## 🎯 Business Challenge

The prototype warehouse contained a large number of materials, tools and components with different quantities, priorities and monetary values.

The available data came mainly from system exports, Excel files and CSV extracts, but it did not immediately provide the transparency required for the project.

The main challenge was to understand:

- How many unique material numbers existed
- Which materials represented the highest inventory value
- How stock was distributed across product groups
- Which materials were most important from an ABC perspective
- Where unusually high quantities, values or data inconsistencies required further attention

The objective was to create a structured view of the warehouse inventory that could support the next phase of the warehouse process design.

---

## 🧩 My Role

I used basic Python and Jupyter Notebook as supporting tools within the warehouse management project.

I selected the relevant inventory and material data, prepared it for analysis and created simple views that helped answer the main business questions.

The focus was on producing understandable and usable results that could be discussed with project stakeholders and translated into process requirements.

## 🔧 Key Responsibilities

## 📦 Inventory Analysis

The analysis focused on the composition, prioritization and value of the warehouse inventory.

Typical topics included:

- Number of unique material numbers
- Inventory quantities
- Unit and total material values
- Inventory value by product group
- ABC classification
- Highest-value materials
- Distribution across warehouse locations
- Concentration of inventory value within specific categories

Basic analytical methods included filtering, sorting, grouping, aggregation, simple joins between datasets and descriptive statistics such as averages, medians and distributions.

This created a clearer picture of which materials and product groups were most relevant from an operational and financial perspective.

## 📈 Visualization

I used simple visualizations to communicate the main findings.

Typical examples included:

- Bar charts for product groups and material categories
- Rankings of highest-value materials

- Comparisons between warehouse locations
- Simple distribution and trend views

The visualizations were created mainly with Matplotlib, Seaborn and basic pandas plotting functions.

The purpose was to make the analysis easier to interpret and support discussions with business and SAP project stakeholders.

The analysis created a structured and reliable view of the warehouse inventory and provided the factual input for the next phase of the project.

- Improving transparency over inventory composition, quantities and values
